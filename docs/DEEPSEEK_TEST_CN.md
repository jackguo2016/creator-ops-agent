上述六次记录响应按配置单价估算合计约 **$0.00495**。计价按输入 $0.30/M、输出 $1.20/M，未计算缓存和非峰值折扣，实际扣费以 DeepSeek 控制台为准。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

后续复查曾发现重试用量漏记，所以上述历史记录不能视为完整扣费或上限。2026-10-03 修复后，新请求已累计重试用量、校验来源成员关系并支持匹配页 AI 重排；旧日志未追溯改写。全量解释仍逐人调用，示例为 20 次。历史“调用成功”只指当时接口与格式验证；本轮修复未新增真实 API 请求，完整真实模型质量评测尚未运行。

## 当时的修改与验证

- 共享模型客户端关闭思考模式，适用于当前三个短任务；
- 审核标签使用七个固定枚举值，非法标签触发已有校验和单次重试；
- 当时的自动测试共 **23 项通过**，这是历史数量；2026-10-04 的全量记录为 116 个测试实例（第一版 84、第二版 32），包含参数化实例，详见 [复查记录](RECHECK_2026-10-04_CN.md)；
- 原开发环境的网页曾保存一条真实审核和模型运行日志；这些历史运行数据未随源码发布，克隆后的页面不会自动出现。

这里只验证了接口、输出格式和项目流程。尚未运行完整的 20 案例真实模型评测，不将 mock 的 100% 指标视为 DeepSeek 的真实效果。一次真实不合格文案审核曾把已出现的产品名误标为缺失，因此输出仍需要人工核对。

## 克隆后如何开始

第一次先用 MOCK。以下假设克隆文件夹名为 `creator-ops-agent`，在它的父目录执行；如果文件夹名不同，替换第一行：

```bash
cd creator-ops-agent
LLM_PROVIDER=mock ./run.sh
```

打开 `http://127.0.0.1:8000`，右上角应显示 `mock`。先导入 `data/creators.csv`，再进行匹配和外联；内容审核可直接提交。MOCK 不调用模型 API，但首次安装依赖可能联网。固定业务评测仍是 20 个虚构案例，不能与 116 个自动测试实例混为一谈。

需要真实调用时，按 [第一版 README 的 DeepSeek 接入说明](../README_WORKFLOW_V1.md#接入-deepseek) 自行创建私有 `.env`、填写有效配置并重启；不要使用或寻找原开发者的配置。真实请求可能计费，模型名与价格以你账户当前可用配置和服务商控制台为准。第二版学习和启动说明见 [完整攻略](AGENT_V2_GUIDE_CN.md)。
